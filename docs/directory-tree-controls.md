# 目录树日常操作

## 使用

- 目录顶部的“新建文件夹”用于新增根目录。
- 在文件夹名称上点击鼠标右键，选择“新建子文件夹”“重命名文件夹”或“删除文件夹”。操作会打开确认窗口，不在每个节点旁增加菜单按钮。
- 在用例名称上点击鼠标右键，选择“重命名用例”。支持手工、Web 和接口用例。
- 鼠标放在内容区目录树与右侧列表之间的细分界线上，显示左右调整光标，按住拖动改变宽度。不会改变平台最左侧导航栏。
- 双击分界线恢复默认宽度；键盘聚焦分界线后可用左右方向键微调，Home 恢复默认。
- 键盘聚焦目录或用例后，Shift+F10 打开右键菜单，F2 进入重命名，Escape 关闭菜单。

目录树宽度默认 310 px，可在桌面端调整到 220–560 px，实际最大值还受内容区宽度限制。偏好在同一浏览器按账号和页面类型记忆，不写入数据库，不影响同事。窄屏采用上下布局，不显示调整分界线。

## 范围与数据边界

统一用例库、手工用例库、Web 和接口用例目录均接入右键操作。通用需求/计划目录复用文件夹操作和宽度调整，用例重命名只针对三类用例，不扩展到需求或计划名称。

- 文件夹仍为共享项目资产，复用现有增删改接口和权限。没有管理权限的节点不展示写入入口。
- 删除文件夹前提示同时删除子文件夹；资源归属回到未归档，不删除用例或历史执行记录。删除后清除失效目录筛选，保留其它查询条件。
- 用例重命名需要可见及编辑权限；Web/接口用例仍仅所属账号可修改，即使其他账号为超级管理员，也不能借此修改私有配置。
- 只读账号不能重命名用例；名称为空、超过长度或表单名称已过期时拒绝更新。
- 手工用例只更新标题，保留原生历史及修改人。Web/接口只更新自身配置名称，不更改步骤、请求参数、关联平台用例、目录归属和执行快照。接口配置名称与关联业务用例标题是两个字段，不做连带改名。
- 当前功能没有新增数据库模型，也没有接入正在讨论的统一版本和正式评审方案。该方案仍未部署。

## 目录树拖放（2026-10-03）

- 手工、Web、接口用例均可从内容区目录树拖到同项目的兼容文件夹，或拖到“未归档”。
- 有目录管理权限的用户可拖动整个文件夹，调整父目录；拖到“项目根目录”可取消上级目录。子目录及用例归属随目录保留。本次不包含同级节点的自定义排序。
- 可放置目标会高亮；禁止跨项目、类型不兼容、拖入自身或子目录。后台继续使用已有 POST/CSRF、账号归属及项目权限检查；同名冲突由原接口提示，不覆盖目录。
- 只接受本页面目录树发起的拖动，外部文字或文件不能触发资源移动。不把用例内容、接口参数或凭据写入拖动剪贴板。
- 保存后返回原页面及筛选条件；如果用例移出当前筛选目录，它会从当前结果中消失。现有表单式移动方式保留。
- 不修改用例正文、步骤、请求参数、执行结果或原生用例历史。不涉及先前未部署的正式版本评审提案。
