# 自动化模块界面规范

Web 与接口模块共用标题栏、列表筛选、分页、空状态、表单分区和执行配置选择器。专业字段保留各自含义，不强行合并执行器或状态枚举。

- 标题左对齐，主操作位于右侧，不在标题旁显示总数。
- 配置、套件、执行和环境使用表格；统计数量放在分页区域。
- 列表支持项目、编号/名称筛选。执行列表额外支持版本、状态和账户本地日期区间。
- 编辑页按基本信息、环境、请求、操作与断言、执行范围、执行设置等分区。所有原字段都必须保留。
- API 请求头、查询参数、环境变量、响应提取和断言支持表格编辑并保留 JSON 模式；Web 使用已有步骤编辑器。只修改界面，不改变执行顺序（Web 按配置编号，API 按 sequence 后按编号）。
- 选择执行配置支持搜索、已选清单及移除；筛选候选项不清空已选项。
- 从列表进入编辑/详情时保留有效内部返回地址和筛选条件；不允许外部返回地址。
- 账户时区用于日期显示、筛选边界和定时首次执行输入，每个请求结束后恢复时区和语言上下文。
- 接口套件保存用户指定的未来首次执行时间；留空则保留原调度或按间隔创建首次时间。未启用时清除下次执行时间。
- 只读账号隐藏写入和执行按钮，表单禁用；后台拒绝修改、生成、复核、保存及执行提交。套件队列同时拒绝只读账号，定时调度暂停失去写权限的套件。私有配置依旧按创建者隔离，超级管理员也不能通过自动化页面查看其他账号的配置。
- AI 生成保留资料输入、待确认问题、人工复核、保存配置流程；未复核或校验失败的接口草稿不可勾选保存。未配置个人模型时明确提示，不回退服务器默认模型。
- Allure、执行明细、正式归档和缺陷/回归数据保留，不把这些不同用途的结果合并或删除。

本轮未新增 Web 定时/CI 能力、独立接口定义库或执行器功能。高级 JSON 字段仍接受后台校验；表格只作为输入方式。

## 验证

新增 `tcms.ai_assistant.test_automation_ui` 覆盖共享页面、私有性、编号筛选、分页、日期/状态、返回安全、只读权限、个人模型提示、字段保留和调度时间。结合原有执行、Allure、自动化生成、目录和回归测试执行。

实际浏览器验收使用独立临时账号与产品，不调用真实 AI，不启动外部测试执行，并在结束后只清理临时验收记录。

## AI 草稿与执行预览补充

### 页面结构

- Web 和接口自动化共用列表筛选、表单分区、分页、操作栏和状态样式。
- AI 草稿页共用生成进度、草稿状态、复核入口、选择工具栏和保存动作。
- Web 草稿采用操作/定位器/输入或预期值表格；接口草稿采用请求摘要和响应断言表格。
- 原始配置 JSON、原文依据和生成资料支持折叠查看。AI 输出以文本展示，不作为 HTML 或代码执行。
- 只读账号可以查看自己的草稿和预览，不提供生成、编辑、选择、保存入口。服务端权限和复核校验仍是最终依据。
- “全选可保存草稿”仅选择已复核、格式有效、未保存的草稿。没有选择时禁止提交；不根据前端状态直接认定复核完成。
- 已保存配置被删除后，仍展示历史草稿；不会生成指向不存在业务用例的链接。

### 执行确认

- 共用“执行预览”视觉结构，但保留各执行引擎的实际行为差异。
- 接口预览仅提供当前账号、当前产品的环境名称、站点、超时；不序列化请求头、变量、认证凭据。
- 执行范围根据当前配置选择和数据组动态显示；数量是预计结果数，并不表示全部一定执行或通过。
- 接口预览显示失败停止策略、Cookie 策略及结果回写选择。数据组格式错误时显示待校验，不显示错误的推算值。
- Web 调试保留必选确认和浏览器操作风险提示，不生成正式执行任务、不回写正式结果。
- Web 正式执行、接口回写、Allure 报告生成与权限规则不因本轮页面整理而改变。

### 独立测试环境菜单

Web 与接口自动化的侧边栏均按“测试环境、自动化配置、测试套件、执行任务”排列。Web 环境列表、新建和编辑页面仅高亮“测试环境”，不再归入“测试套件”。保留配置页和套件页的环境快捷入口。此调整不改变环境归属、权限、调试/执行选环境的方式或已有数据。

### 环境导航精简

本次调整取代上文“保留列表页环境快捷入口”的约定：环境管理统一从左侧独立“测试环境”菜单进入，配置页和套件列表页标题栏不再重复提供该入口。

Web 调试、Web 套件执行、接口执行保留环境选择。需要现场补建环境时，使用共用的 `automation/environment_action.html` 显示“新建环境”操作，仅对有写入能力的账号显示，并保留所选产品范围。Web 与接口各自的环境参数和执行规则不合并，也不改变配置的环境绑定方式。

### 环境选择与快捷新建

所有实际配置或执行表单中的环境选择统一使用 `automation/environment_control.html`：Web/接口套件新建及编辑、Web/接口执行、Web 单配置调试。选择框旁显示“新建环境”，不在表单底部重复显示；只读账号隐藏链接，筛选和历史展示不提供该操作，没有环境字段的配置表单也不增加字段。

新建使用新标签页并设置 `noopener noreferrer`。Web 套件编辑切换产品时链接随当前字段更新；接口按路由产品固定范围。返回原标签页时，仅刷新本人可选的环境及必要的预览资料，不刷新整个表单、不自动改变已选环境，也不触发执行或保存。网络失败保留原选项。

### 术语与环境配置去重

- 业务界面统一“项目”，表示当前平台使用 Kiwi Product 作为隔离及版本归属范围；不新增另一套项目实体，不改 API 参数 `product` 或历史数据。
- “开发任务”承载负责人、开发状态、工时和开发说明，不等同于测试执行任务。
- “自动化脚本”是业务测试用例关联的可执行操作/请求/断言，不把 AI 模型配置、环境配置等所有配置都叫脚本。
- 面向用户统一“执行任务”，内部 TestRun、WebRun、APIRun 名称、路由和状态值保留。
- “环境参数”是步骤可引用的测试参数，不是操作系统环境变量。
- Web 环境的“前置执行脚本”每组数据先执行一次，再复制 Cookie/本地存储；登录是其用途之一，不将业务用例的前置条件等同于可执行脚本。
- 缺陷修复后只复查原失败项的流程显示“缺陷复测”；真正检查变更对其他功能影响的“回归测试”不改名。旧 `regression` 标识及报告快照保留。
- 看板改为“阶段记录完整度”，其统计口径不变，仅反映当前筛选范围的阶段记录比例，不代表测试进度、需求覆盖率或发布质量。

Web 套件表单只选择执行环境，不再提供可编辑的站点与证书覆盖项。Web/API 套件均显示只读环境预览；执行时可以另选环境。Web 旧存储字段保留供历史快照与内部接口兼容，保存时取所选环境值，执行快照优先读取环境的最新值。

`web_testing.0007_bind_legacy_suite_environments` 为每个未绑定环境的旧套件建立独立兼容环境，保留原归属、站点和证书策略，不继承其他环境的参数或前置脚本。迁移幂等，反向不删除用户可能已经编辑的环境。上线前备份相关套件/环境数据及源代码。
