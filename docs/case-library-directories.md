# 总用例库目录

入口：测试管理 → 用例库（`/ai/cases/`）。

布局为平台菜单、内容区左侧目录树、右侧列表。点击用例名称或详情打开弹窗，再进入原有页面查看或编辑完整配置。

## 目录与类型分工

- 在指定项目下创建业务目录，例如“用户中心 → 登录 → 边界场景”。新目录使用 `case_group` 类型，三类用例均可归档到该目录。
- 手工、Web 和接口模块复用同一 `ProjectResourceFolder` 以及 `ProjectResourceAssignment`，目录变动无需两处维护。
- 原有 `case`、`web_case`、`api_case` 目录不改名、不删除、不重建归属。总用例库标记为原有类型目录，可移动到共享业务目录下面。
- 切换测试类型仍保留当前业务目录；选父目录时包含对应类型的子目录用例。切换项目会清除旧目录筛选。
- 目录数字只统计当前账号可见、符合名称和类型筛选的用例，包括子目录。左侧用例预览与当前右侧列表一致。
- 删除目录及子目录仅清除归属，用例回到未归档，不删除用例。

## 权限与安全

共享业务目录对相关项目成员和有本项目用例访问权的账号可见；目录管理允许项目成员、项目内用例拥有者，以及已有全局用例管理权限的账号，排除只读账号。
原有类型目录维持既有管理权限。

目录共享不改变用例权限：手工用例遵循原有对象权限，Web/接口用例和配置仍只属于当前账号。
用例归档单独检查修改权限、所属项目和目录类型；移动目录禁止跨项目、错误类型、自环和祖先循环。
所有写操作使用 POST 和 CSRF，返回地址只允许本站。

迁移 `0032_common_case_directories` 仅增加资源类型选项，没有对现有目录或用例作数据改写。
