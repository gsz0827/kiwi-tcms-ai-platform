## 关键拒绝场景

- 调试结果、错误计划/构建、错误 Jenkins 提交 UUID。
- 未执行完成、取消执行、没有归档、待审批、审批驳回。
- 旧报告、损坏快照、审批签字不匹配、审批人停用。
- 审批后修改执行项或自动化结果，即使通过数量不变也不放行。
- 新增阻断缺陷、规则变更后复用旧特批。
- 令牌失效、其他套件执行、只读账号、网络异常和等待超时。
- 客户端拒绝错误返回值，异常时覆盖旧成功记录，不输出令牌。

### 实机发现与修复

- #1 在归档与门禁轮询并发时触发 MariaDB 锁顺序死锁；门禁查询改为非锁定读取，
  并在返回前重新验证令牌和账号权限，避免已撤销令牌放行。
- #3 在归档提交边界读取到缓存的旧执行任务，误判 report_execution_changed；
  改为归档可见后刷新任务，并重新核对上下文，不修改签字快照。
- 为以上并发情况新增三项回归测试；#1/#3 保留为诊断记录，不计作预期阻断通过。
- #4/#5 已分别验证接口放行和 P1 阻断；#6 的专用 Web 验收样例误用了登录字段定位器，
  导致测试失败且后续阶段按设计跳过。已按实际模板修正样例，旧结果保留，不修改业务页面。
