# 用例库直接新建

- 用例库右上角显示“新建用例”，由原来的“必须先选产品”改为全部项目视图也可使用；全部项目视图先在弹窗中选择产品。
- 选中产品/目录时，按钮进入对应产品的结构化编辑器，并预填“保存目录”。
- 产品根目录与可见的用例文件夹右键提供“新建用例”，不依赖全局文件夹管理权限；仍要求添加用例权限、账号有效且非只读角色。
- 新建表单的保存目录限定为当前产品、当前账号可见的用例/共享业务目录。根目录用空选项表示，不新增“未归档”目录或虚拟分配记录。
- 新建用例和目录归档在同一事务内保存；目录失效时回滚新用例及历史记录，保留当前输入与错误提示。跨产品或错误目录类型的请求被拒绝。
- 保存后进入同一业务用例的详情页，“返回用例库”指向实际保存目录。
- 手工录入使用已有表格编辑器；不强制关联需求，不生成自动化配置或执行任务。需求来源的手工设计入口及来源快照机制保持不变。
- 编辑已有用例不通过新增目录字段修改路径，继续使用现有目录树移动操作。

无需数据库迁移。相关回归测试在 `tcms.ai_assistant.test_scenario_creation`。
