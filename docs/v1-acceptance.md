# V1.0 交付验收

本项目是基于 Kiwi TCMS 二次开发的测试管理实践平台，面向面试展示和小团队试运行。原有测试管理能力来自 Kiwi TCMS，不将上游能力描述为独立从零开发。

## 本轮收尾范围

- 补齐关键操作审计模型及只读后台查询：报告审批、风险放行、门禁修改、报告导出、成员变更、目录删除和个人模型凭据更新。
- 门禁编辑限制在操作者有权限的项目中；只读角色不能借管理员界面写入。
- 审计记录保留用户名快照；禁止常规模型更新、批量更新、删除和使用已存在的主键覆盖记录。账号删除后可保留历史操作者信息。
- 审计落库失败记录错误日志，嵌套事务隔离失败，不把正常业务操作变成数据库事务错误。
- 保留门禁字段历史。旧门禁仅补一份明确标记为“初始快照”的历史，不伪造过去的操作记录。
- 构建支持依赖下载超时、重试、缓存及显式的包索引参数；默认仍使用 PyPI。
- 镜像构建排除本机临时修复目录、备份目录和私钥文件。

## 验收方法

1. 在开发容器运行相关回归测试，审计测试不再排除。
2. 创建独立数据库卷，将迁移前的完整数据库备份恢复进去，核对记录数量及个人模型配置能否解密。
3. 新建独立验收项目，通过真实 HTTP 请求执行接口自动化，通过真实 Chromium 浏览器执行 Web 自动化。
4. 验证正式执行先生成未执行的 TCMS 任务；后台结果需要人工确认归档后才回写，不自动发布。
5. 故意设置错误断言验证失败归档、缺陷流转，再纠正断言执行复测。此数据用于验收平台流转，不冒充实际业务系统缺陷。
6. 验证失败报告不能在没有风险放行理由时批准，复测报告可审批签字，原失败报告的数据快照保持不变。
7. 从源码构建应用、Web 工作进程及 Allure 工作进程镜像，复测数据库迁移和关键页面。

数据库恢复与演示数据只存在于独立验收环境，不覆盖或混入原开发项目。验收过程中不调用外部付费 AI，已有真实模型接入能力由之前的测试及现有功能验证覆盖，本轮不声称重新做了供应商可用性测试。

## 审计与部署边界

- 审计只读限制是应用层保护，不是数据库管理员无法修改的防篡改证明。直接 SQL、数据库账号权限、备份权限和独立日志留存仍由部署环境控制。
- 来源地址只使用服务器连接地址，不直接信任客户端提交的转发请求头。新增反向代理时需重新配置并验证可信代理边界。
- 数据库与附件应分别备份；恢复个人模型及执行快照时必须保留原部署的 `SECRET_KEY`，否则加密内容无法恢复。密钥不能进入 Git 仓库。
- 发布门禁只提供质量判断，不等于已经完成部署。Jenkins 接口令牌、账号授权和流水线仍需按具体团队配置。
- 本地 HTTPS、私有报告权限和后台任务租约不替代真实生产环境的监控、容量规划与灾备。

## 交付结论

详细结果见 [V1.0 验收记录](v1-acceptance-results.md)：新镜像相关回归 1007 项（993 通过、14 跳过），独立 MariaDB 关键回归 99 项通过；真实自动化、报告、权限隔离及数据库恢复检查已通过。该结论针对面试项目阶段交付，不等同于企业生产上线认证。

不再扩展导航菜单作为收尾标准。后续以真实项目试运行发现的问题为主，避免为了功能数量不断扩展未验证的入口。

## 可复现的镜像验收方式

本次使用源码构建的 `Dockerfile.ai` test 目标，再以其为基础构建 `Dockerfile.web-worker`；没有依赖开发容器 `/tmp` 下临时安装的测试包。

```sh
docker build -f Dockerfile.ai --target test -t kiwi-v1-tests-base .
docker build -f Dockerfile.web-worker \
  --build-arg KIWI_BASE=kiwi-v1-tests-base -t kiwi-v1-tests .
docker run --rm kiwi-v1-tests /venv/bin/python manage.py test \
  tcms.ai_assistant tcms.web_testing tcms.allure_reporting \
  --settings=tcms.settings.test --noinput
```

默认从 PyPI 下载依赖。网络受限时可为两个构建命令显式传入可信的 `PIP_INDEX_URL`，默认重试 5 次、下载超时 120 秒，并使用 BuildKit 缓存。不要为了加速关闭 TLS 校验或修改依赖版本。

MariaDB 验收须使用独立数据库账号、网络及测试库，不要对开发数据库或生产数据库直接运行会建库/删库的测试命令。

上面的完整模块发现命令可用于复测；本次验收的计数来自相关模块根目录 `test*.py` 的显式发现，未声称覆盖上游全部测试集。
