# 测试计划层级与统计口径

新建/编辑页面使用“上级计划（可选）”。不设“是否为父级计划”：同一计划可以同时有上级和下级。详情及目录右键提供“新建子计划”，预填上级、产品、版本及类型，可在保存前调整；不会复制上级用例或执行记录。

## 目录与权限

- 产品 → 自建文件夹 → 计划 → 下级计划，文件夹和计划使用不同图标。
- 子计划跟随当前账号可见的顶层计划的目录归属，只出现一次；文件夹筛选使用同一归属规则。历史子计划文件夹分配保留，不做数据迁移。
- 只有可见顶层计划可以拖动到文件夹；改变上级通过编辑计划完成，避免把文件夹归档误当成修改计划关系。
- 搜索、版本或启用状态过滤排除上级时，匹配的子计划仍在继承目录中显示，不额外暴露被过滤或无权限的上级。
- 父子关系只接受同一产品，表单排除自身与后代；已有跨产品关系不参与层级展示和汇总。历史异常循环只在显示层断开，不修改数据库。
- 汇总只纳入有权查看的连续下级链路，不穿透无权限的中间计划；用例按用例查看权限，执行记录按所属执行任务的查看权限。

## 汇总

- “本计划用例/执行任务”维持直接关联统计，创建执行任务仍只使用本计划已确认用例。
- “含下级计划汇总”覆盖本计划和所有可见下级，含停用计划与不同版本。
- 用例数按业务用例编号去重；同一用例引用到多个计划只算一次。不纳入旧数据中跨产品用例引用。
- 执行任务按任务编号，执行记录按执行记录编号，历史多轮执行和回归分别统计，原始结果不变。不纳入构建产品不一致的历史异常任务。
- 与 Kiwi 原生一致：状态权重为零表示未完成，大于零表示通过，小于零表示未通过；自定义状态遵循配置权重。完成率=非零权重记录/全部记录；通过率=正权重记录/非零权重记录。
- 没有执行记录时完成率显示“—”；没有已完成记录时通过率显示“—”，不会误显示100%。该统计包含历史结果，不代表最新一轮发布门禁结论。
- 执行任务页签可切换“本计划 / 本计划及下级”，分页保留统计范围，并显示所属计划。

## 验证

`tcms.testplans.tests.test_hierarchy` 覆盖多级汇总、去重、权限隔离、新建预填、目录归属和筛选、历史数据不变、范围分页、循环及跨产品异常。

无需数据库迁移，不改变历史报告数据快照。
